# 输出格式修复
上一次输出未能通过 JSON 解析。本次仍然使用原输入和原始证据重新起草，不引用上一次输出作为事实，不执行任何工具。
只返回一个 JSON 对象，必须含 kind、answer、citations 三个字段。即使是一句追问或很短的口语回答，也不能直接返回散文或代码围栏。
- 有依据：{"kind":"answer","answer":"中文回答","citations":[{"id":"本轮证据 id","quote":"本轮逐字原文"}]}。
- 必要澄清：{"kind":"clarify","answer":"一句必要的澄清问题？","citations":[]}。
- 信息不足或对方取消：{"kind":"silence","answer":null,"citations":[]}。
历史仅用于理解指代；步骤、链接含义、条件和联系人必须由本轮 evidence 支持。只有参考文档链接时，不声称文档中还有更详细说明或具体字段。不得把“填写测试用途”扩写成证据没有列出的必填内容。
